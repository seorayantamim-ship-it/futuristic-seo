# Futuristic SEO website

A responsive static website for Futuristic SEO, owned by Muhammad Rayan.

## Files
- `index.html` — page content and metadata
- `styles.css` — responsive styling
- `script.js` — mobile navigation and email inquiry form

## Preview locally
Open `index.html` in a browser.

## Free publishing options
You can publish this static site using GitHub Pages, Netlify, or Cloudflare Pages. Upload the three website files (or the contents of this folder) to your chosen host. A free hosting subdomain is usually provided.

## Important setup checks before publishing
1. Confirm the business email address. The address supplied for this build was `seorayantamim@gmial.com` (the domain is spelled `gmial.com`). If this is a typo, replace it in both `index.html` and `script.js`.
2. Replace the demo portfolio cards with real work only. They are explicitly labeled as demo placeholders.
3. Review the sample package prices and edit them to match your actual rates and service scope.
4. The contact form uses `mailto:`. It opens the visitor's email app and does not save inquiries to a database. A hosted form service or backend is needed for automatic online submissions.
5. No domain has been registered and the site has not been deployed by this package.

## SEO notes
The page includes a title, meta description, mobile responsive layout, semantic sections, and index/follow robots directive. After publishing, add a sitemap, connect Google Search Console, verify the domain, and submit the sitemap. SEO results are not guaranteed.
